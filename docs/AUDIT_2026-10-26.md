## 性能与代码组织

- 将 600 多行的混合流式适配拆为 `responses_stream.py` 与 `anthropic_stream.py`，`protocol_streams.py` 保留兼容导出。共享 UTF-8/SSE 解析、usage 和终止状态逻辑，协议自身负责输出项/内容块。
- Responses 文本和工具参数只在最终输出时 join，去除每个分片重建全部前缀的平方级复制；Anthropic 不再保存未使用的完整工具参数副本。
- HTTP 请求体限制和响应头处理改为纯 ASGI 中间件，避免响应流经过 BaseHTTPMiddleware 的额外桥接；lifespan 在异常退出时也执行 shutdown。
- ECharts 改为仅注册折线图所需模块，图表组件按需加载。
- 增加可复现的 Python 开发依赖、Vue/Vitest 组件与构建测试；移除前端自身 file 依赖及生产构建中不需要的 devtools。

| Vertex 配置 | 只初始化一次，外部变更不刷新；保存读取动态表单而非提交快照，凭证可能滞留 | 共用草稿同步逻辑，提交快照；凭证先于模式开关保存；空凭证不提交、只显示已配置状态，成功后清空已提交输入且保留期间的新编辑；补齐开关与输入的可访问名称 |
| 保存期间编辑 | 用户在保存中把字段改回旧服务器值，会被误判为未编辑并覆盖 | 草稿增加提交确认基线，在更新 store 前记录实际保存值；Basic、Features、Vertex 全部使用；回归覆盖“旧值 → 提交新值 → 保存中改回旧值” |
| 批量配置生命周期 | 锁定或关闭面板后，后续字段仍可能继续保存；模型映射绕过超时和旧轮询保护 | 共用 `configSaveGuard.js`，在每步前后校验会话与面板状态；模型映射通过 store.postConfig 使用同样的 15 秒超时和轮询失效规则；已开始的服务器写入不承诺回滚 |
| 重复请求 | 未改动的 Responses / Claude 映射每次保存都发送请求 | 对照提交快照与 store，只发送发生变化的映射；成功后更新对应基线与 store，保留新编辑 |
| 缓存性能 | 每次读取都会扫描并重建同键剩余队列，连续消费 N 条出现平方级工作量 | 使用 deque.popleft，遇到过期项继续向前，返回首个有效结果；全局过期清理与堆压缩保持；并发消费、缓存 null、混合过期和计数一致性回归通过 |

当前验证：596 项 Python 测试 + 119 项子测试、38 项前端测试、生产构建、七种浏览器场景通过。浏览器还实际操作 Vertex 表单，验证仅变更开关时不会提交已有凭证的空输入，保存后管理密码清空。新增合成缓存基准脚本 `scripts/benchmark_response_cache.py`。测试、基准与浏览器均未调用真实计费上游。

本轮兼容性变化：不再把格式错误或不支持的内容悄悄转换成部分请求；客户端应发送完整工具历史、有效字符串 ID 和 JSON 对象参数。Chat 转换入口仅接受当前已实现的文本/图片内容；需要音视频等原生能力时，应使用 Gemini 原生入口并以其上游支持范围为准。

## 兼容边界与仍需验证的部分

1. **真实上游联调**：本地 SDK 序列化和 HTTP 模拟通过，但未用服务账号或 Express 密钥发起实际请求。模型、区域、额度、特定 JSON Schema 和工具组合的服务端支持仍需在目标部署环境确认。
2. **明确的能力范围**：原生 Vertex 的工具调用限普通模型；encrypt / encrypt-full / auto 与工具组合返回 400。AI Studio 转换、原生 Vertex、Vertex 伪流式仅支持 n=1。Vertex 原生图片目前要求 base64 data URL，远程 URL 不会被悄悄丢弃。
3. **高级协议能力**：Responses 不提供服务端会话、后台任务和内置文件/搜索工具。原生 Gemini 没有与 parallel_tool_calls=false 等价的开关；Anthropic 与 Gemini 的签名不能跨提供方验证。音视频、文件、多模态工具结果和推理历史的完整互操作尚未实现，不能当作完整协议认证。
4. **统计精度**：每个密钥 RPM 使用秒级窗口；图表/分钟汇总仍按分钟桶统计，“本统计周期”计数为重置后累计值，不是任意时刻精确滚动的 24 小时值。
5. **部署验证**：构建、组件、ASGI 和 Chromium 桌面/手机截图验收通过。仍需在真实反向代理下验证 SSE 空闲超时、断连、缓存头。长期原地构建的旧哈希资产保留策略应由部署流程管理。
6. **后续维护**：已抽出工具转换、客户端生命周期及前端草稿同步职责；部分旧模块仍较大，可继续依行为测试逐步拆分。有限测试无法证明零缺陷，以上未验证项不计为已完成。

## 协议依据

- OpenAI 本地 SDK 的 `EasyInputMessageParam`：type 为可选字段；对照的是当前锁定 SDK 的类型定义。
- [Google 思考签名文档](https://ai.google.dev/gemini-api/docs/generate-content/thought-signatures)：真实签名原样回传；导入其他模型历史时的兼容标记。
- [Gemini generateContent 参考](https://ai.google.dev/api/generate-content)：function call/result 的关联标识与生成配置。
- [Anthropic 流式文档](https://platform.claude.com/docs/en/build-with-claude/streaming)：内容块事件生命周期、累计 usage 与流内 error。
- 本地锁定的 Google SDK FunctionCallingConfig 只有 mode/allowed_function_names，不含 parallel_function_calls。

- [OpenAI 函数调用指南](https://developers.openai.com/api/docs/guides/function-calling?api-mode=responses)：多个函数调用和结果关联；本项目仍使用锁定的 SDK，未宣称支持指南中全部新能力。
- [Anthropic 工具调用结果文档](https://platform.claude.com/docs/en/agents-and-tools/tool-use/handle-tool-calls)：tool_use 参数为对象，tool_result 位于 user 消息且先于普通内容。
- 本地 OpenAI SDK 的 `ChatCompletionToolMessageParam`：工具结果 content 可为字符串或文本 part 数组；两者都要保持工具结果语义。

## 推送前全面复审

本轮补齐配置与凭证更新、鉴权、独立 Vertex 入口、前端保存和部署配置的检查。

- 凭证解析改用 JSONDecoder，正确处理字符串中的花括号，支持单对象、对象数组、连续或逗号分隔对象；拒绝残缺后缀和非对象内容。
- 新凭证整批完成结构与私钥校验后才替换运行中的凭证，失败保留旧配置；RSA 解析在线程执行，不阻塞事件循环。移除更新时重复初始化与无关的远程模型配置拉取，避免慢网络造成保存超时。
- 同一项目的不同服务账号和签名密钥按实际身份去重，不再按项目名或文件名误删。Google 凭证影子配置同步更新，防止重新载入旧值。
- 数字配置拒绝布尔值、非整数、NaN/Infinity 和错误类型；错误返回 400/422，不再截断或返回 500；思考等级配置增加实际值校验。
- Web 密码使用 UTF-8 常量时间比较，修复中文密码触发 TypeError；主网关和独立 Vertex 采用同一密码判定与不区分大小写的 Bearer 提取。
- 独立 Vertex 入口与主网关共享工具历史及内容块校验，拒绝无关联工具结果，规范化工具文本数组；lifespan 退出清理 SDK 客户端池和 HTTP 客户端。
- 前端在任何配置写入前检查数字、思考等级、模型别名的完整性和重复项；“全部保存”先验证两个面板，避免可预检的错误导致部分保存。网络失败仍可能造成部分成功，界面继续按真实结果反馈。
- Docker 为非 root 用户创建并授权默认存储目录；排除审查截图与验证脚本；纠正原 Dockerfile 关于使用 frozen lock 的不实注释，实际依旧按 requirements.txt 安装。
