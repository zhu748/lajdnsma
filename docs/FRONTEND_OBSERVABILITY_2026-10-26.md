# 控制台与请求观测完善

本轮实现前端专项审查中的运行中请求统计、请求阶段时间线、Token 口径、日志交互、配置草稿及布局改进。

## 请求与上游的口径

- ASGI 中间件登记每条客户端请求，正常发送结束、失败或取消时释放。响应返回 `X-Request-Id`，CORS 允许浏览器读取。
- AI Studio 生成/Embedding、Vertex 原生 SDK 和 Vertex OpenAI 直连分别观察真实上游尝试。客户端请求数、上游在途调用数、请求合并池各自独立。
- 客户端结束后，尚在取消收尾的上游调用仍计入在途数，直至实际关闭。
- 时间线记录接收、路由、上游开始、首有效输出、首正文、上游结束和网关开始返回内容。空 delta、心跳和 usage-only 帧不算首输出；非流式上游不报告无法观测的首字时间。
- 请求阶段与日志自动关联 request_id；上游日志附加 attempt_id。所有密钥只以脱敏标识展示。
- 日志中的失败不依赖 HTTP 500：HTTP 200 流内错误仍标为失败。

## 用量

- 请求结果分别显示输入、输出（包含思考）、思考及总 Token，不重复叠加思考。
- 优先保留原始上游 usage，缺失值显示“未提供”；仅输入和输出均已知时推导总量，并标注来源。
- 缓存结果和复用结果用量不计入本请求的新上游结果消耗。
- 上游尝试的已知用量与最终返回结果分别展示，缺失 usage 的尝试有单独计数。它们均不是账单估算。
- 统计清零显示周期开始时间；重置前已开始的请求结束时不会把旧周期结果加回新周期。
- 所有数据明确限定为当前进程。默认单 worker 部署可直接使用；多 worker/多实例需要各自查看或接入外部聚合，当前没有跨实例持久化。

## 控制台

顶部实时运行指标与请求记录在 AI Studio、Vertex 两种模式都可见。请求列表支持编号/模型/路径搜索、协议/后端/状态/时间范围筛选、慢请求筛选、分页、时间线与各次尝试展开、JSON 导出。网关趋势覆盖两种后端。

系统日志支持稳定记录 ID、搜索、级别筛选、暂停更新、自动跟随、新记录提示和当前筛选导出；修复批量追加后停止跟随、缓冲淘汰时展开详情串位。

协议说明移到运行信息之后并默认折叠；提供完整接口地址和 Base URL 分别复制。导航标记当前分区。表格在窄屏局部滚动，运行指标使用两列布局。

配置收起保留草稿，取消修改才重新初始化；标记未保存修改，支持基础/功能分组保存与全部保存。密钥测试启动、清理、导出及统计重置统一超时、卸载取消；配置保存后清空管理密码。密钥表提供模型筛选，并将“日额度”改为说明口径的本地估算。

## 数据接口与保留范围

| 接口 | 内容与刷新 |
| --- | --- |
| `/api/runtime-data?after=N` | 每 2 秒；当前指标、全部运行中请求、新结束记录 |
| `/api/logs?after=N` | 每 2 秒；增量日志及游标、进程标识、缺口标志 |
| `/api/dashboard-data?summary=true` | 每 5 秒；密钥统计及趋势，省略配置、日志和请求明细 |
| `/api/dashboard-data` | 首次登录、手动刷新、保存后及每 30 秒；完整配置与旧接口兼容数据 |

以上 GET 接口均使用已有管理认证，前端通过 Authorization 请求头传递凭证。隐藏标签页暂停轮询，锁定/卸载中止实时请求；旧会话响应不得写回。

结束记录保留 300 条；日志增量缓冲 1000 条；每条请求的时间线最多 100 个阶段，尝试明细最多保留 100 条已结束记录和仍活动的尝试。游标缺口与进程重启在界面提示。下载仅包含当前保留和筛选的数据，服务端输出用于完整日志归档。

## 验证

新增真实 ASGI + httpx MockTransport 契约覆盖三种兼容协议的流式/非流式、上游尝试、Token、请求编号、计数释放、接口认证、增量游标和精简统计响应。另有摘要重放、心跳排除、重置代次、未知用量、日志缺口及上游收尾测试。

前端回归补充日志跟随、稳定展开状态、暂停恢复、草稿保留/取消、服务重启和管理请求超时。生产产物通过 `npm --prefix hajimiUI run build` 同步至 `app/templates`。

完整 Python 回归：628 项测试与 119 项子测试通过。前端 55 项用例均输出通过结果，生产构建成功。

当前执行环境的 Vitest 用例完成后进程收尾会超时；一个不包含项目代码的最小 Node 测试也能复现，额外诊断确认 DOM 环境 teardown 已完成。没有通过强制退出把超时改写成正常通过。

本地 Chromium 两个版本均启动失败；远程浏览器访问工作区 localhost 返回 ERR_CONNECTION_REFUSED。因此未完成本轮浏览器截图验收。当前 AI Studio、Vertex Express、Google 凭证均未配置，没有调用真实计费上游或验证生产代理链路。

## 补齐审查清单中的细节

- 普通重试与可选 PVP 不可用的回退路径均记录退避，时间线展示计划等待秒数、失败状态码、原因和下一次尝试序号。
- 密钥选择事件说明冷却、RPM/本地周期限额跳过、同密钥重试或 PVP 钉住；新尝试记录前后脱敏密钥、模型/后端变化及关联的上次失败原因。
- Vertex 自动路由回退记录格式切换原因与下一模型；最后一个路由失败后不再执行没有下一次尝试的等待。
- 上游尝试区分空响应、缺少结束标记的截断流及错误事件；SDK 状态码同时读取 HTTP 异常与 Google SDK code。
- 首页周期/小时/分钟的缩略数字、密钥汇总及各模型用量全部补齐精确值 title。
- 观测序列化失败只标记信息不完整，不能替换有效响应；新增验证保证该行为。
- 实际模拟 HTTP 契约增加 429 → 退避 → 换密钥 → 成功，验证时间线、Token、尝试序号及脱敏；浏览器 QA 脚本增加时间线和精确值断言，修正多个断线提示同时出现时的选择器。

以上是功能实现与本地验证状态；受环境阻塞的验收仍单独列出，不记为完成。
